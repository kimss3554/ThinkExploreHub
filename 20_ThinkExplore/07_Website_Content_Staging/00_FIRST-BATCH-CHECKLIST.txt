배치 전 필수 확인
═════════════════════════════════════════════════════════════════

각 파일마다 확인:

  ✓ 학생 이름 제거?
  ✓ 학교명 제거?
  ✓ 학번/성적 없음?
  ✓ 전화번호/카카오톡 없음?
  ✓ 제출용 문서 원본 아님?
  ✓ 사진 속 명찰/학교명 안 보임?

공개 동의:
  ✓ 동의 확인됨? → "공개 가능"
  ✓ 동의 불명확? → "동의 확인 필요"

배치 완료 후
═════════════════════════════════════════════════════════════════

모든 준비가 완료되면 다음과 같이 알려주세요:

  "자료 배치 완료.

  Stage 1.5 조사를 시작해 주세요.

  추가 조건:

  1. README.md와 모든 NOTES.md는 자산 목록과 수량에서 제외합니다.
  2. 선별 폴더 밖은 탐색하지 않습니다.
  3. 심볼릭 링크와 바로가기를 따라가지 않습니다.
  4. 먼저 파일명과 메타데이터를 점검합니다.
  5. 민감 자료 가능성이 있으면 내용을 열지 않습니다.
  6. 학생부, 성적표, 학교 제출 자료, 현재 고등학생 제출물은 조사하지 않습니다.
  7. 동의가 명확하지 않은 자료는 '공개 가능'이 아니라 '동의 확인 필요'로 분류합니다.
  8. 아직 파일 이동·리사이즈·압축·이름 변경·HTML 적용은 하지 않습니다.
  9. README.md와 NOTES.md를 제외한 실제 자료 수를 보고합니다.
  10. ASSET_INVENTORY.md, CONTENT_GAPS.md, CONTENT_SHORTLIST.md를 작성한 뒤 멈추세요.

  Git add, commit, push, 홈페이지 코드 수정은 하지 마세요."
