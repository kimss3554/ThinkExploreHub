# Elementary Education Cases

**1차 배치**: 5개 (사례 연결 문서 포함)

초등 학생의 글쓰기, 질문노트, 활동 자료를 배치하세요.

## 필수 파일

이미지만 넣으면 Claude Code가 자료 간 관계를 모릅니다.
반드시 사례 설명 파일을 포함하세요.

```
ELEM-CASE-01.txt      ← 필수 (사례 설명)
ELEM-WRITING-BEFORE-01.jpg
ELEM-WRITING-PROCESS-01.jpg
ELEM-WRITING-AFTER-01.jpg
(추가 2개 선택)
```

## 사례 설명 파일

`ELEM-CASE-01.txt`에는 다음만 기록:
```
사례 ID: ELEM-CASE-01
대상: 초등 저학년 또는 고학년
활동 목적: ...
자료 순서: ...
보여줄 핵심 변화: ...
공개 동의: ...
익명화 상태: ...
```

**절대 기록 금지**: 이름, 학교, 학년, 성적

## 권장 포함 항목

**필수**:
- 처음 쓴 글 (전)
- 수정 과정 (중)
- 완성 글 (후)

**추가 선택** 중 2개:
- 질문 노트
- 마인드맵
- 탐구·독서활동
- 발표 자료

## 권장 파일명

```
ELEM-CASE-01.txt
ELEM-WRITING-BEFORE-01.jpg
ELEM-WRITING-PROCESS-01.jpg
ELEM-WRITING-AFTER-01.jpg
ELEM-MINDMAP-01.jpg (또는 다른 추가 자료)
ELEM-ACTIVITY-01.jpg (또는 다른 추가 자료)
```

**주의**: 학생명 제거, 익명화 필수
