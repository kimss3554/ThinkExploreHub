# Middle School Education Cases

**1차 배치**: 4개 (사례 연결 문서 포함)

중등 학생의 탐구, 글쓰기, 프로젝트 자료를 배치하세요.

## 필수 파일

이미지만 넣으면 Claude Code가 자료 간 관계를 모릅니다.
반드시 사례 설명 파일을 포함하세요.

```
MIDDLE-CASE-01.txt       ← 필수 (사례 설명)
MIDDLE-INQUIRY-QUESTION-01.jpg
MIDDLE-RESEARCH-PROCESS-01.jpg
MIDDLE-PPT-SLIDE-01.jpg (또는 02)
MIDDLE-PRESENTATION-01.jpg
```

## 사례 설명 파일

`MIDDLE-CASE-01.txt`에는 다음만 기록:
```
사례 ID: MIDDLE-CASE-01
대상: 중학생
활동 목적: ...
자료 순서: ...
보여줄 핵심 과정: ...
공개 동의: ...
익명화 상태: ...
```

**절대 기록 금지**: 이름, 학교, 학년, 성적

## 자료 포함 범위

✅ 수업 중 작성한 질문 노트
✅ 연습용 자료 조사 활동
✅ 수업 중 제작한 PPT/포스터
✅ 발표 자료 또는 발표 사진
✅ 탐구 방법을 배우는 프로젝트

❌ 학교 제출물 원본
❌ 수행평가 제출 파일
❌ 개인정보 포함 자료

## 권장 포함 항목

**필수**:
- 탐구 질문 또는 계획
- 자료 조사 과정
- PPT 대표 슬라이드 1~2장 (이미지)
- 발표 자료 또는 사진
