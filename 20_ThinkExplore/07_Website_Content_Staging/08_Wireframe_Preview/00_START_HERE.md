## 4️⃣ 주의사항

### ✅ 반드시 확인하세요

**각 파일마다 확인:**
- [ ] 학생 이름이 보이지 않는가?
- [ ] 학교명이 표시되지 않았는가?
- [ ] 학번·성적이 없는가?
- [ ] 전화번호·카카오톡 프로필이 없는가?
- [ ] 제출용 문서 원본이 아닌가?
- [ ] 사진 속 명찰·학교명이 안 보이는가?

**공개 동의:**
- 동의 확인됨? → "공개 가능"
- 불명확함? → "동의 확인 필요"

### ❌ 절대 금지

```
❌ 학교생활기록부
❌ 성적표
❌ 학번 표시 자료
❌ 현재 고등학생 제출물
❌ 자기평가서
❌ 개인정보 포함 자료
```

## 5️⃣ 파일 선별 팁

### 이미지 자료
- **형식**: JPG 또는 PNG (원본 해상도 가능)
- **파일명**: 학생명 제거, 익명 ID 사용
- **예**: `ELEM-WRITING-BEFORE-01.jpg` ✅
- **예**: `OOO학생_글쓰기.jpg` ❌

### 사례 설명 파일
- **형식**: TXT (단순 텍스트)
- **내용**: 각 폴더 안의 템플릿 참고
- **절대 기록 금지**: 이름, 학교, 학년 상세, 성적

### 파일 크기
- 이미지: 5~10MB 범위 (너무 크지 않게)
- 텍스트: 몇 KB (간단하게)

9. README.md와 NOTES.md를 제외한 실제 자료 수를 보고합니다.
10. ASSET_INVENTORY.md, CONTENT_GAPS.md, CONTENT_SHORTLIST.md를 작성한 뒤 멈추세요.

Git add, commit, push, 홈페이지 코드 수정은 하지 마세요.
