# Student Achievements & Admission Results

**상태**: 2차 배치 대상 (첫 배치에는 포함 안 함)

학생 수상, 영재원 합격, 진학 소식을 배치하세요.

**목표**: 소식 2~3개

## 자료 형식

✅ 익명 텍스트 메모 (.txt 파일)
❌ 증명서·합격장 이미지 (개인정보 위험)

## 기록 원칙

**메모에 포함할 정보**:
```
자료 ID: RESULT-ADMISSION-01
구분: 진학 소식 / 수상 소식
연도: 2026
공개 가능한 범위: 학교 유형 또는 대학 계열
사실 확인: 완료
공개 동의: 확인 필요
사용 문구 후보: 함께한 학생의 진학 소식
```

**절대 기록하지 않을 정보**:
```
학생 이름
학교명 (학교 유형만 가능)
성적
성명
학번
```

## 권장 파일명

```
RESULT-AWARD-01.txt
RESULT-GIFTED-01.txt
RESULT-ADMISSION-01.txt
```

## 기록 예시

```
자료 ID: RESULT-AWARD-01
구분: 대회 수상
연도: 2025
공개 가능한 범위: 대회명과 수상 사실
사실 확인: 완료
공개 동의: 확인 필요
사용 문구 후보: 수강생 수상 소식
```

## 1차 배치 가능 여부

❌ **첫 배치에 포함하지 않습니다.**

초등·중등 핵심 사례(12~15개)로 첫 와이어프레임을 설계한 후
2차 배치 시 수상·진학 소식을 추가합니다.
