# 생각탐구 콘텐츠 자리 미리보기

실제 홈페이지가 아니라 사진·영상·내용의 자리를 먼저 확인하는 로컬 와이어프레임입니다.

## 확인 순서
1. `index-wireframe.html`을 브라우저에서 엽니다.
2. 초등, 중등, 성장기록 페이지를 차례로 봅니다.
3. 점선 박스 안의 파일명을 확인합니다.
4. 그 파일명에 맞는 자료만 선별 폴더에 복사합니다.
5. 사진 크기 조절이나 디자인 편집은 하지 않습니다.
6. `ELEM-CASE-01.txt`, `MIDDLE-CASE-01.txt`에는 사실만 짧게 적습니다.
7. 준비 후 “자료 배치 완료”라고 알립니다.
