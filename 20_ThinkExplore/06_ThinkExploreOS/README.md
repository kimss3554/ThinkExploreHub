# ThinkExploreOS

생각탐구 진학지도교습소의 **운영 시스템 루트**입니다. 홈페이지 제작, 분석 자료, 수업·산출물 관리 등 실제 운영 업무를 이 저장소에서 진행합니다.

## 구조

| 경로 | 용도 |
|------|------|
| `CLAUDE.md` | Claude Code 작업 규칙·핵심 정체성 |
| `WORK_BOARD.md` | 현재(NOW)·다음(NEXT)·체계화(SYSTEMIZE) 업무 보드 |
| `PROJECT_REGISTRY.md` | 외부 프로젝트 위치 등록부 |
| `DECISIONS.md` | 주요 결정 기록 |
| `docs/` | 참고 문서 |
| `prompts/` | 재사용 프롬프트 |
| `templates/` | 산출물 템플릿 |
| `outputs/` | 완성 산출물 |
| `archive/` | 보관 자료 |
| `.claude/` | Claude Code 설정 (rules / agents / skills) |

## 시작하기

1. `WORK_BOARD.md`에서 지금 가장 급한 일(NOW)을 확인한다.
2. 작업 위치는 `PROJECT_REGISTRY.md`에서 찾는다.
3. 중요한 결정은 `DECISIONS.md`에 남긴다.

## 원칙

- 실제 학생 개인정보는 저장소에 넣지 않는다.
- 기존 프로젝트/파일을 임의로 이동·삭제하지 않는다.
- 긴급도와 실제 운영 필요를 최우선한다.
