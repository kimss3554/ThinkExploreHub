# 학생부·고등학생 지도 준수 원칙

## 1. 절대 금지 범위

생각탐구교습소와 ThinkExploreOS는 다음 업무를 제공하거나 홍보하지 않는다.

- 학교생활기록부 파일, PDF, 캡처, 사진, 출력물, 원문 데이터 수령
- 학생부 내용을 이용한 유료 분석, 평가, 첨삭 또는 관리
- 학생부 문구의 작성, 수정, 추천, 대필
- 학교 교사가 학생부를 잘 작성하도록 만들기 위한 문구 설계
- 현재 고등학생의 수행평가 결과물 대필 또는 직접 작성
- 현재 고등학생의 탐구보고서, 자기평가서, 소감문, 발표자료 대필
- 학생이 제출할 글을 대신 완성하거나 제출 가능한 형태로 작성
- 학생 이름, 학교, 학번, 성적, 학생부, 교내 활동 이력 등 개인정보 원본 보관
- 학생부 자료를 기반으로 한 포트폴리오 제작 또는 홍보
- '생기부 관리', '세특 관리', '생기부 컨설팅', '세특 작성', '수행평가 완성 대행' 등의 표현 사용

고등학생 또는 보호자가 학생부 자료를 보내려는 경우 수령하지 않으며, 이미 전달된 경우 저장·복사·분석하지 않고 즉시 삭제를 요청한다.

## 2. 초등·중등 수업의 허용 범위

초등·중등 과정은 고등학교 입학 전에 필요한 진로역량과 학업역량을 기르는 교육으로 정의한다.

허용되는 교육 범위:

- 읽기와 문해력
- 어휘력과 요약력
- 질문 만들기
- 자기 생각 말하기
- 논리적 글쓰기
- 자료 조사와 출처 확인
- 탐구 질문 설정
- 초등·중등 수준의 연습용 탐구 활동
- 발표와 토론
- 협업과 의사소통
- 자기주도적 학습 습관
- 진로 탐색과 관심 분야 확장
- 고등학교 입학 전 진로·학업 역량 강화

모든 결과물은 학생이 직접 생각하고 작성한다.
교사는 질문, 구조 이해, 학습 방법, 피드백을 제공하지만 학생의 결과물을 대신 작성하지 않는다.

권장 표현:

- 진로역량강화 수업
- 학업역량강화 수업
- 탐구역량 수업
- 읽기·질문·글쓰기·발표 역량
- 고등학교 입학 전 준비해야 할 사고력과 표현력
- 자기주도적 탐구 습관
- 자료를 읽고 자기 생각으로 정리하는 힘
- 초등·중등 과정에서 기르는 진로·학업 기초역량

## 3. 고등학생 상담의 허용 범위

고등학생 대상 서비스는 다음 범위로 제한한다.

- 수시 전형 일반 상담
- 정시 전형 일반 상담
- 대학 및 학과 정보 안내
- 모집요강과 공개 입시정보 해설
- 공개된 전형 결과와 지원 전략 설명
- 고교학점제 및 선택과목에 관한 일반 정보
- 학생과 보호자의 의사결정을 돕는 진로·진학 상담

상담 시 학교생활기록부 파일이나 학생 개인정보 원본을 받지 않는다.
학생부 문구, 수행평가, 탐구보고서, 자기평가서 작성에 관여하지 않는다.
특정 학생의 학생부를 근거로 유료 분석하거나 개선 방향을 제시하지 않는다.

## 4. 홍보 문구 금지어

다음 표현은 홈페이지, 블로그, 인스타그램, 상담자료, 계약서, 브로슈어에서 사용하지 않는다.

- 생기부 컨설팅
- 생기부 관리
- 세특 관리
- 세특 작성
- 세특 완성
- 학생부 분석
- 학생부 설계
- 학생부 로드맵
- 비교과 관리
- 수행평가 대행
- 탐구보고서 완성 대행
- 자기평가서 작성
- 학교 제출물 첨삭·완성
- 생기부에 잘 기록되도록
- 학생부 경쟁력 상승
- 생기부 질적 상승

기존 자료에 위 표현이 있다면 자동으로 삭제하지 말고, 수정 필요 목록으로 보고한다.

## 5. 권장 대체 표현

- 생기부 컨설팅 → 수시·정시 진학상담
- 생기부 로드맵 → 진로·학업 설계
- 세특 관리 → 교과 이해와 탐구역량 강화
- 수행평가 대비 → 발표·글쓰기·자료해석 역량 강화
- 탐구보고서 완성 → 탐구 과정과 구조를 배우는 교육
- 비교과 관리 → 진로 탐색과 자기주도적 학업역량
- 고등학생 결과물 코칭 → 공개 입시정보 기반 진학상담

## 6. 개인정보 저장 규칙

ThinkExploreOS와 관련 프로젝트에는 다음 정보를 저장하지 않는다.

- 학생부 파일과 캡처
- 학생 이름과 학교가 함께 표시된 자료
- 학번
- 성적표
- 교내 활동 내역 원본
- 수행평가 제출물 원본
- 자기평가서 원본
- 학생부 기반 상담 기록
- 학생을 식별할 수 있는 상담자료

학생 사례가 필요한 경우 이름, 학교, 학년, 지역, 성적 등 식별정보를 제거한 익명 사례만 사용한다.

## 7. AI 작업 규칙

Claude Code와 다른 AI는 다음 요청을 거절하거나 경고해야 한다.

- 학생부 파일 분석
- 세특 문장 작성
- 학생부 기재용 문장 추천
- 학생이 학교에 제출할 수행평가 대필
- 탐구보고서 완성본 대필
- 자기평가서 대필
- 학생부 기반 합격 가능성 분석

허용되는 작업:

- 공개 모집요강 요약
- 수시·정시 제도 안내
- 초등·중등 역량 교육과정 설계
- 연습용 글쓰기 활동
- 일반적인 탐구 방법 교육
- 개인정보가 없는 공개 입시자료 분석
- 교습소 내부 운영문서와 홍보문구의 준수 여부 점검

## 8. 프로젝트별 적용

**Website:**
- 학생부 분석, 세특 관리, 수행평가·보고서 작성 지원으로 오해될 문구를 점검한다.
- 초등·중등의 진로·학업역량 강화와 수시·정시 일반상담 중심으로 수정한다.

**SchoolAnalysis:**
- 공개된 학교·입시자료만 사용한다.
- 개별 학생의 학생부나 개인정보와 결합하지 않는다.

**ContentProducts:**
- 학생부 작성, 세특 작성, 학교 제출물 대행 상품을 만들지 않는다.
- 문해력, 질문, 글쓰기, 발표, 진로 탐색, 탐구 방법을 교육하는 자료만 제작한다.

**ThinkExploreOS:**
- 모든 에이전트, 스킬, 템플릿, 프롬프트가 이 규칙을 우선 적용한다.
